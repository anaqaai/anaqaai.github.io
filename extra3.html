WURFL Device Capabilities

Capability Description
brand_name Returns the brand/manufacturer of the device (e.g., Samsung, Apple)
model_name Returns the specific model name of the device (e.g., iPhone 15 Pro, Pixel 8)
is_tablet Returns Boolean value to detect if the device is a tablet for UI adjustments
device_os Returns Operating system of the device (iOS, Android, etc.)
